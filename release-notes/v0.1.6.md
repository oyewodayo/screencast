Briefcast on macOS and Linux catches up with Windows: captions and editing by transcript, noise removal, background removal and the AI voice, sharing and email, and a camera bubble that follows your settings. Where something is still Windows-only, it now says so. This release also introduces one-click image background removal across Image Editor, Board, and Whiteboard, interactive visual Layers panels, floating UI overlays that eliminate canvas layout jumps, and major responsiveness and performance optimizations.

### AI Background Removal for Images (Image Editor, Board & Whiteboard)

- **One-click background removal for images**: Remove backgrounds directly from photos in the Image Editor, Board, and Whiteboard canvases.
- **Client-side inference across Windows, macOS, and Linux**: Powered by an in-browser ONNX runtime pipeline with zero external server dependencies, running consistently on all desktop platforms.
- **Transparent cutouts**: Clean transparency support without dark fringing or unwanted white mattes.
- **Interactive processing animation**: While background removal runs, the image displays a dynamic breathing color pulse, laser scanline sweep, and status badge with zero CPU main-thread overhead.
- **Context menu and toolbar shortcuts**: Trigger background removal from the right-click menu or the property panels with full undo/redo support.

### Robust & Efficient File Compression

- **Background task minimization & non-blocking execution**: Compression can be minimized to a lightweight floating background widget at any time—via the header minimize button, "Minimize to Background" button, or by clicking outside the modal. The full app remains completely unblocked, allowing users to present, record, annotate, or edit without interruption.
- **Below-normal process scheduling (zero CPU interference)**: Background compression processes execute with `BELOW_NORMAL_PRIORITY_CLASS` (Windows) and `renice +10` (macOS/Linux), ensuring screen recording, audio processing, presentations, and live UI frames receive top priority with zero stutter or dropped frames.
- **Dedicated "Compress" sidebar dropdown option & Bottom Docker button**: Right alongside "Convert", files can now be compressed directly from the sidebar file menu, folder galleries, dock context menus, and the bottom docker action bar.
- **Sleek & compact bottom docker buttons**: Optimized docker action buttons (Convert, Compress, Move/Copy, Transfer, Show in folder, Delete) with proportionate compact padding, unified height, and clear typography.
- **Smart multi-format media compression**:
  - **Videos**: High-efficiency H.264 compression with presets for Balanced (~50-70% size reduction), Small File / Maximum compression (~75-85% size reduction), or High Quality, with optional resolution downscaling (1080p, 720p, 480p) and web faststart.
  - **Images**: Quality-tuned compression for JPEG, WebP, and PNG with optional dimension constraints, dramatically lowering file weights for web and messaging.
  - **Audio**: Configurable bitrate compression for MP3, AAC, and OGG formats.
  - **PDF & Documents**: Standard DEFLATE ZIP archive compression for documents and reports.
- **Real-time progress & space-savings reporting**: Displays live compression progress and shows exact before/after file sizes with the percentage and megabytes saved upon completion.
- **Preserve or replace original**: Safely keep the original file or replace it in-place with the optimized version.

### Whiteboard & Board Layers Panels

- **Dedicated Layers panel**: Click the new Layers icon in the top toolbar to view all canvas elements (images, shapes, text, tables, notes, drawings, and connectors) in visual stacking order (front to back).
- **Easy selection of covered elements**: Select backward or completely covered shapes with a single click in the layers list.
- **Cross-platform pointer drag-and-drop**: Smooth drag-and-drop reordering that works identically on Windows, macOS, and Linux, bypassing native webview drag conflicts.
- **Direct controls**: Bring forward / send backward one step with dedicated chevrons, toggle element locks, and delete items straight from each layer row.

### Floating Canvas Panels & UI Stability

- **Floating overlay panels**: Board and Whiteboard tool panels now float smoothly over the canvas rather than docking as flex columns.
- **Zero canvas shifting**: Selecting, editing, or deselecting images no longer shrinks the viewport or pushes the board canvas left and right.
- **Docker-aware bottom clearance**: Floating panels dynamically detect the bottom dock height (`--docker-height`) and maintain clean clearance above screen recording and camera controls.

### Global Annotation Pointer & Smooth Ink Drawing

- **Jitter-free pointer tracking**: Completely eliminated erratic extrapolation overshoots and pointer "dangling / dancing" by locking the hand pointer hotspot directly to real hardware cursor coordinates with zero latency.
- **Anchored fingertip contact**: Optimized press-and-draw animations to scale smoothly from the hotspot origin `(0, 0)` without translational offsets, preventing the finger from wobbling or detaching from the contact point during clicks and drags.
- **Buttery smooth freehand strokes**: Enhanced ink curve generation with Catmull-Rom spline smoothing (`0.55`) and balanced streamline (`0.45`), combined with sub-pixel micro-jitter filtering and rounded end caps for fluid, natural handwriting and drawing across mouse and stylus inputs.

### Performance & Memory Optimizations

- **Instant sidebar icon click response**: Upgraded sidebar toolbar icons and category tabs with enlarged 28px hit targets, immediate active press animations (`scale-90`), component-level memoization, and non-blocking asynchronous category switching to eliminate click latency and misclicks.
- **File watcher loop elimination**: Fixed a recursive autosave-to-watcher refresh loop by filtering internal project and temporary files, drastically lowering background CPU usage, disk I/O, and UI redraw thrashing.
- **GPU-accelerated animations**: Visual effects and scanning lines run via CSS compositor keyframes, avoiding JavaScript timer loops or requestAnimationFrame overhead.
- **Responsive pointer capture**: Unified pointer capture across list reordering eliminates stray event listeners and ensures buttery smooth 60fps drag tracking.

### Captions, editing by transcript and noise removal on macOS and Linux

- **Offline captions, Edit by transcript and filler-word removal** now work on macOS and Linux. The speech engine (whisper.cpp) is part of the installers, as it is on Windows; the speech model (about 150 MB) downloads the first time you use it. On Linux it produces the same words as the Windows engine, timed to within a tenth of a second.
- **Remove noise** uses the same noise model on every system.

### The AI tools on Linux and Apple Silicon Macs

- **Background removal** for a webcam picture-in-picture, **face matching** in Find and hide, the **AI voice** and the **live camera background** now run on Linux (64-bit) and on Macs with Apple Silicon (macOS 14 or later). They download their engine the first time you use them. They run on the processor rather than a graphics card, so they take longer than on Windows. Intel Macs are not supported by this engine version, and the features stay hidden there.
- **The camera bubble's border style and colour** (Screen Options) were ignored on macOS and Linux. They apply now.

### Sharing and email on macOS and Linux

- **Email this file** opens Mail on a Mac, or your desktop's mail client on Linux, with the document already attached. **Share with an app** is not available there (those systems have no share window); **Copy file**, **Copy contents** and the one-click **WhatsApp, Telegram, Teams, Slack and Discord** buttons are, for the apps you have installed.
- **Copying and pasting files** works with Finder and Linux file managers: copy files there and paste them onto the timeline, or copy a document and paste it into a chat.
- **Beam** (text and links between your phone and computer) can use the computer's clipboard and open links on it.

### Smaller things

- **Pick a colour from the screen** works on Linux (X11).
- **Briefcast's small companion files** (a video's edits, chapters and so on) are hidden in Finder and in GNOME Files and Dolphin, as they are in Windows Explorer.
- Settings and the AI voice panel no longer say a feature is Windows-only where it isn't.

### Still Windows-only

These need work that only Windows has so far: the **editable pointer, click ripples, shortcut keys on screen and auto-zoom at clicks** (they follow the mouse and keyboard); the **privacy blur**; **USB phone transfer** (Wi-Fi transfer works everywhere); the **screenshot picker's overlay** (macOS and Linux take screenshots the simpler way); and **Download as PDF** for documents, because the web engine on macOS and Linux can't draw a document's headers, footers and page numbers (Word, Markdown and web page export all work). On a Mac, recording system sound needs a virtual audio device such as BlackHole, and picking a colour from the screen isn't available.
