Briefcast v0.1.7 is a major recording-engine, performance, and cross-platform parity release. It eliminates live camera preview lag with a zero-IPC localhost MJPEG push pipeline, redesigns the Recording Studio setup modal for a calmer, more mature look and instant button/close responsiveness, dramatically speeds up post-stop assembly and audio cleanup, adds Wayland PipeWire screen capture and Intel/AMD VA-API hardware encoding on Linux, brings native privacy permission onboarding and multi-monitor window capture to macOS, and introduces Image to PDF conversion.

### Zero-Lag Live Camera Preview & Real-Time Background Effects

- **Eliminated multi-second movement lag**: Replaced excessive DirectShow buffering (`-rtbufsize 100M`, which could queue over 160 stale frames during stalls) with low-latency `-rtbufsize 3M -fflags nobuffer -flags low_delay -probesize 32 -analyzeduration 0 -framerate 30` and fast bilinear scaling so movement and lip-sync stay tightly locked in real time.
- **Zero-IPC localhost MJPEG push stream**: Live background previews now stream directly from a local `multipart/x-mixed-replace` HTTP server (`http://127.0.0.1:<port>/stream`) into the preview image, eliminating per-frame Tauri IPC polling, JavaScript `Blob`/`ObjectURL` GC churn, and polling jitter while incurring 0% JPEG encode overhead during recording once the setup modal closes.
- **Instant preview startup (zero blank spinner)**: Switched feed startup from full 55 MB SHA-256 hashing to fast presence checks, cached the winning DirectML GPU vs. CPU ONNX execution provider per session after a brief one-time trial, displayed live raw camera frames on frame #1 while the first matte warms up (~100 ms), and fixed a render-#1 camera-ownership race between `getUserMedia` and `ffmpeg`.
- **2–3.5× faster real-time matting & blur**: Added optimized downscale-to-planar and bilinear alpha upscale routines in `pixel-convert` so Robust Video Matting runs on a fast `<= 256px` grid while keeping your foreground sharp at full bubble resolution, paired with a cache-friendly downscale-blur-upscale `blur_rgb_fast` and fixed-point integer compositing.
- **Zero idle CPU during pause**: Live camera matting, compositing, and TCP serving automatically pause when recording is paused, and a brief post-inference iGPU breather prevents DirectML from starving UI paints on integrated GPUs.

### Mature Recording Studio Modal & Instant UI Responsiveness

- **Redesigned Recording Studio modal**: Refined proportions (`max-w-[1220px]`), layered light/dark surfaces, subtle 1px hairline rings, a framed Stage preview mat showing real monitor/window thumbnails behind an unclipped camera bubble, grouped Devices & Output controls, and custom tactile pill toggle switches replacing bright green checkbox boxes.
- **Live microphone level meter**: Added a real-time segmented VU meter right next to the microphone picker in the setup modal (with off-screen `IntersectionObserver` pausing and ~30 fps cap) so you can verify your mic is active before starting.
- **Instant Close & button response**: Deferred `MediaStreamTrack.stop()` and `AudioContext.close()` off the synchronous React unmount frame (and delayed mic meter initialization by 180 ms on open), removed GPU-heavy full-viewport `backdrop-blur-sm`, isolated modal layout containment, added optimistic local state with `React.startTransition` so button clicks paint in `<16 ms` without waiting on parent `Dashboard` reconciliation, and debounced the Blur Strength slider with a live `%` readout.
- **Lower modal & idle overhead**: Conditionally mounted the setup modal only when open, merged camera/audio enumeration into one `get_connected_devices` IPC, removed a dead `WH_SHELL` window hook call, and closed the modal 120 ms before starting capture so preview devices release cleanly.

### Faster Live Capture, Post-Stop Assembly & Audio Enhancement

- **Parallel post-stop assembly**: Camera sidecar, microphone, and system-audio teardown now run concurrently; separate webcam retiming runs in parallel with voice enhancement and final muxing; and mismatched restart segments normalize in parallel.
- **SIMD + parallel hum removal & direct WAV decode**: Replaced single-threaded trig-loop FFT analysis with `realfft` + `rayon` parallel frame processing, and added direct `hound` WAV reading with 3:1 decimation for local 48 kHz recordings to skip spawning an extra `ffmpeg` subprocess.
- **Hardware-accelerated sidecars & re-encodes**: Enabled hardware encoding (`hw_encoder::detect`) for Windows separate webcam sidecars, restart part normalization, and webcam retiming, avoiding redundant scale filters and `split=1` graphs.
- **Lower live capture overhead**: Captured microphones as 1-channel mono (halving temp disk I/O), sized WASAPI buffers to `default_period`, batched WAV writes, cached `QueryPerformanceFrequency` in a `OnceLock`, removed synchronous GDI/PNG cursor capture from Windows `WH_MOUSE_LL` (preventing OS cursor stutters), deduplicated mouse hooks when Editable Pointer is active, moved `.progress.log` polling to O(1) 4 KB tail reads off async workers, bounded hardware encoder probes to 10 s on parallel startup threads, and released async mutexes before awaiting finalization during watchdog stall recovery.

### Phone Camera Sync, Pause/Resume & Recording Reliability

- **Phone camera pause/resume & faster stop**: Wired pause/resume into `PhoneCaptureHandle` across both the main window and floating overlay, split phone stop into a ~50 ms chunk flush followed by parallel `stop_recording` and phone finalization (with snapshotted first-frame timing alignment), and switched chunk writes to a persistent 256 KB `BufWriter`.
- **Recording hygiene & safety guards**: Added a 200 MB free disk space pre-check before starting capture, automatic startup cleanup of orphaned temp intermediates in `%TEMP%\briefcast-capture`, numeric collision suffixing (`Name (2).mp4`) that preserves custom filenames, and non-blocking start audio cues.

### Cross-Platform Parity (Linux, macOS & Windows)

- **Linux Wayland PipeWire screen capture**: Added XDG Desktop Portal (`org.freedesktop.portal.ScreenCast`) + PipeWire (`gst-launch-1.0 pipewiresrc ! videoconvert ! y4menc`) capture via `zbus`, preserving camera overlays, separate webcam sidecars, PulseAudio/PipeWire-Pulse audio mixing, hardware encoding, and pause/resume on modern Wayland desktops (Ubuntu 22.04/24.04, Fedora, GNOME, KDE), with automatic `x11grab` fallback when `DISPLAY` is available and the portal is absent.
- **Linux Intel/AMD VA-API hardware encoding**: Added `h264_vaapi` auto-detection (`/dev/dri/renderD*`) with `-vaapi_device` and `format=nv12,hwupload` wired across all Linux recording modes and phone-camera normalization, alongside existing NVIDIA NVENC support.
- **Linux click, pointer & shortcut telemetry**: Replaced Linux stubs with pure-Rust `x11rb` pointer, click, and modifier-shortcut tracking, and lifted click/pointer sidecar persistence out of Windows-only guards so Windows, macOS, and Linux all generate `.clicks.json` and `.pointer.json` sidecars.
- **macOS native privacy onboarding**: Replaced subprocess permission probes (`screencapture -c` / `osascript`) with native `CGPreflightScreenCaptureAccess()`, `CGRequestScreenCaptureAccess()`, and `AXIsProcessTrusted()`, wired to an upfront permissions banner in the Recording Studio modal with one-click System Settings shortcuts and focus auto-refresh.
- **macOS multi-monitor window capture, system audio & shortcuts**: Added CoreGraphics display bounds enumeration (`CGGetActiveDisplayList` / `CGDisplayBounds`) and display-local window cropping so window capture works accurately on secondary displays; enabled virtual loopback system-audio mixing alongside camera overlays and separate webcam capture; added macOS modifier-shortcut keystroke and multi-button click telemetry; and cached `list_avfoundation_devices` with a 15 s TTL and 10 s timeout.
- **Overlay exclusion & Windows DPI precision**: Wired main-thread, Apple Silicon-safe `NSWindowSharingNone` overlay exclusion on macOS (excluding control/countdown chrome while preserving live annotations), explicitly initialized `DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2` at startup on Windows for mixed-DPI multi-monitor setups, and fixed a Windows startup issue where applying `SetWindowDisplayAffinity` to hidden frameless overlays caused `snip-overlay` to appear on launch.
- **Linux & macOS capture polish**: Restored shared `webcam_sidecar_path` for separate webcam recording on macOS/Linux, wired `capture_cursor` on both platforms, added `-thread_queue_size 64`, and filtered V4L2 metadata nodes (`index != "0"`) from Linux camera listings.

### Other Improvements & Fixes

- **Image to PDF conversion**: Added direct image-to-PDF conversion support.
- **macOS build & editor state fixes**: Fixed `libc` dependency configuration on macOS and resolved missing refs and move/copy menu state issues in Dashboard and TimelineDocker.
